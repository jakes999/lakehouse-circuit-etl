## Title

Build a Production-Ready Azure Databricks ETL Pipeline | Bronze, Silver & Gold

## Description

Build an end-to-end Azure Databricks data engineering pipeline using ADLS Gen2, managed identity, Unity Catalog, Auto Loader, Delta Lake and Databricks Workflows.

You’ll learn how to ingest synthetic customer and order data, apply practical quality rules, quarantine invalid records, deduplicate business keys, create Gold analytics tables and deploy the pipeline with Databricks Asset Bundles.

What you’ll build:
- Secure ADLS access without embedded keys
- Bronze ingestion with Auto Loader
- Silver validation and quarantine
- Gold customer and daily-sales models
- Scheduled Databricks Workflow
- Bundle-based deployment and automated tests

All sample data is synthetic. Never show access keys, tokens, subscription IDs or personal account details in a recording.
